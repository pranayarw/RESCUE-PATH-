# RESQPATH
### AI-Powered Road Emergency Assistance Platform

**Tagline: Connecting People to Life-Saving Services Faster.**

## About the Project

RESQPATH is a road emergency assistance platform designed to help users quickly find nearby hospitals, ambulance services, police stations, towing providers, and tyre repair shops during road accidents and emergencies.

It brings essential emergency resources together in one platform to support faster and easier access to assistance.

## Key Features

- User Registration and Login
- Real-Time GPS Location Detection
- Nearby Hospital and Trauma Centre Finder
- Ambulance Service Discovery
- Nearby Police Station Finder
- Towing and Vehicle Recovery Services
- Tyre Repair Shop Locator
- Interactive Maps and Navigation
- Emergency SOS System
- Emergency Contact Management
- Multilingual AI Emergency Assistant
- Offline Emergency Support
- Dark Mode and Light Mode
- Road Safety Information

## Project Structure

The submitted source code includes:

- `lib/` – Main application source files
- `scripts/` – Development and utility scripts
- `package.json` – Project dependencies and scripts
- `pnpm-lock.yaml` – Dependency version information
- `tsconfig.json` – TypeScript configuration
- `.replit` – Replit environment configuration

## Installation and Execution

**Prerequisites**
- Node.js
- npm or pnpm

**Step 1: Install Dependencies**

```bash
npm install
```

Or:

```bash
pnpm install
```

**Step 2: Start the Application**

```bash
npm run dev
```

Or:

```bash
pnpm run dev
```

Refer to `package.json` for the exact available scripts.

## Important Note

The `node_modules` directory has been excluded to reduce the source code ZIP size. All required dependency information is maintained in the package configuration and lock files.
